# Aeronautics E-book — Ultimate Aviation Vault ✈️

> An interactive, 1,000-chapter learning experience that takes readers from the fundamentals of flight to advanced aeronautical and aerospace engineering.

## Overview

Aeronautics E-book is a browser-based study website built around a structured curriculum of **1,000 chapters grouped into 100 parts**. The experience combines a flight-deck-inspired interface with a chapter reader, curriculum navigation, reading progress, and chapter mastery activities. Chapter titles and their part assignments are sourced from `chapters_data.js`.

## Highlights

- **1,000-chapter curriculum** arranged as 100 sequential parts, with 10 chapters per part.
- **Interactive reader** with chapter navigation, page navigation, and a direct chapter jump (1–1,000).
- **Table of contents** with chapter browsing, part selection, search, discipline tabs, and reading-status filters.
- **Study progress** including chapters read, remaining chapters, completion indicators, and overall progress bars.
- **Chapter mastery quizzes** and saved quiz answers.
- **Reader themes:** light, dark, and system preference.
- **Reader identity portal** for a reader name and email address. Email authorization-code delivery depends on server-side SMTP configuration.
- **Visual learning assets** including aircraft, aerodynamics, engine, cockpit, blueprint, atmosphere/weather, avionics, flight-control, rotorcraft, supersonic, structures/landing-gear, and orbital diagrams.
- **Responsive, aviation-inspired interface** with custom styling and typography.

## Run locally

### Option A — run with the included Python server

1. Install Python 3.9 or later.
2. Open a terminal in the project directory (the directory containing `server.py`).
3. Run:

   ```bash
   python server.py
   ```

4. Open the local address printed by the server in your browser. If the server does not print one, check `server.py` for its configured host and port.

The included server handles the website's API routes, including session logging and email authorization-code requests. Email delivery requires valid SMTP settings; without them, code requests may be recorded locally rather than delivered.

### Option B — static preview

You can open `index.html` directly for a quick visual preview, but features that call server API routes (such as session logging or email-code delivery) require the Python server to be running. A local HTTP server is generally the most reliable way to test the full experience.

## Chapter data format

`chapters_data.js` exposes the master dataset on the browser global `window.AERONAUTICS_CHAPTERS`. Each chapter record contains its chapter number, title, and assigned part label. The dataset currently contains 1,000 records, numbered 1 through 1,000.

Example record shape:

```js
window.AERONAUTICS_CHAPTERS = {
  "1": {
    "num": 1,
    "title": "Introduction to Aeronautics",
    "part": "Part 1: Discovering Aeronautics (1–10)"
  }
};
```

When editing the curriculum, preserve unique sequential chapter numbers and ensure each chapter's `part` label matches the intended part and range. The README curriculum index should be regenerated if chapter titles or part assignments change.

## Reader progress and browser storage

The client uses browser `localStorage` for reader preferences and study state, including theme, current chapter, chapters marked as read, quiz answers, and related progress values. This means progress is associated with the browser profile/device unless the application is extended with account-backed synchronization. Clearing browser site data can remove locally saved progress.

## Email / server configuration

The Python server supports email authorization-code requests. Configure SMTP credentials using the environment variables or configuration mechanism implemented in `server.py` and `smtp_config.json`. **Do not commit real SMTP passwords, app passwords, or other secrets to source control.** Use environment variables or a private local configuration file, and keep production credentials out of public repositories.

## Notes and limitations

- The chapter index documents the curriculum structure; the interactive chapter content and page rendering are implemented by the website's JavaScript.
- SMTP email delivery only works when the server is configured with valid credentials and the host permits outbound SMTP.
- The website's progress data is locally stored unless a separate backend synchronization feature is implemented.
- Aircraft and aerospace learning material is educational and should not replace approved training, aircraft manuals, maintenance documentation, or applicable aviation regulations.
